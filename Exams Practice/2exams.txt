Assignment name  : shift
Expected files   : shift.c
Allowed functions: write
--------------------------------------------------------------------------------

Write a program that takes a string and a number n as arguments.

The program must shift each lowercase letter of the string by n positions
in the alphabet. If a letter goes beyond 'z', it must continue again from 'a'.

The program displays the resulting string followed by a newline.

If the number of arguments is not 2, the program displays a newline.

Examples:

$> ./shift "abc" 2 | cat -e
cde$
$> ./shift "xyz" 2 | cat -e
zab$
$> ./shift "hello" 30 | cat -e
lipps$
$>

Assignment name  : search_insert
Expected files   : search_insert.c
Allowed functions: None
-----------------------

Write a function that takes a sorted array of distinct integers, its size, and
a target integer as arguments.

The function must return the index of the target if it is found in the array.

If the target is not found, return the index where it should be inserted in
order to keep the array sorted.

The function must return `0` if the array is empty.

Examples:

```text
Input:
nums = [1, 3, 5, 6]
target = 5

Output:
2
```

```text
Input:
nums = [1, 3, 5, 6]
target = 2

Output:
1
```

```text
Input:
nums = [1, 3, 5, 6]
target = 7

Output:
4
```
